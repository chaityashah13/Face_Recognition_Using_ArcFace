Activate venu:
cd C:\DL_Mini_Project
venv\Scripts\activate

Photo capture on laptop:
python Group_19_1.py capture --name Shah_Chaitya --count 60

Split, train and test:
python Group_19_1.py split --force
python Group_19_1.py train
python Group_19_1.py test


TO run the live demo:
python Group_19_1.py run
